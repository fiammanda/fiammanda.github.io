## Behind the Scenes

本站基于 Hono 搭建，运行于 **Cloudflare Workers**。内容以 Markdown 文件形式存放在 **R2**（使用 **Marked** 和 **Prism** 配合大量自定义 renderer 与 hook 进行渲染），统计数据则记录在 **D1**。源码可于隔壁分支查看！

This simple site is built with **Hono** and powered by **Cloudflare Workers**, with source markdown files (parsed by **Marked** and **Prism** via extensive custom renderers and hooks) in **R2** and statistics in **D1**. View the other branch for codes!
